# DựngVideo

Tool dựng video dọc 9:16 theo nhịp nhạc (Python + FFmpeg) cho kênh @hieusichungkhoan.
Phong cách học từ kênh CapCut @rasooliarts: chia màn hình bằng mask, cắt theo beat, chữ động, lưới ảnh, chồng lớp.

- Hướng dẫn sử dụng: [HUONG_DAN.md](HUONG_DAN.md)
- Kiến thức dựng video (timeline, quy trình, beat sync, đặc tả layer engine): [KIEN_THUC_CAPCUT.md](KIEN_THUC_CAPCUT.md)
- Bối cảnh cho Claude Code: [CLAUDE.md](CLAUDE.md)

Chạy nhanh trên Windows: `1_CAI_DAT.bat` → `4_CHAY_THU_DEMO.bat` → kéo thả thư mục lên `2_TAO_VIDEO_TU_THU_MUC.bat`.
